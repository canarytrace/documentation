## Releases

### 5.5.13
Download: `docker pull ghcr.io/canarytrace/synthetic:dev-5.5.13`

🚀 New Features
- A new version name, Canarytrace Synthetic 5, which better reflects its purpose.
- Fully redesigned Canarytrace 5 built on Playwright. It offers the same features as Canarytrace 4 but with a new testing framework and additional capabilities.
- Gradually, we will enable and make available features that are currently in the testing phase.
- Canarytrace 4 is deprecated and will no longer be supported. Please migrate to Canarytrace 5.
- The deployment, result storage, and configuration methods remain the same as in Canarytrace 4, making the transition to the new version easy.

---

<b>Canarytrace 4 is deprecated as of 2024.</b><br/>At the beginning of 2024, Canarytrace 5, built on Playwright, is being released.<br/><br/>
